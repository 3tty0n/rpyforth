# Third-party materials

The MIT License in [`LICENSE`](LICENSE) applies to the original RPyForth
implementation, tests, and benchmark infrastructure unless a file states
otherwise. It does not replace or override the licenses of third-party
materials included for benchmarking or compatibility testing.

The repository records the known licenses and provenance of those materials in
the following files:

- [`benchmark/NOTICE`](benchmark/NOTICE) — index of benchmark notices
- [`appbench/NOTICE`](appbench/NOTICE) — the mixed-license appbench 1.4 suite
- [`shootout/NOTICE`](shootout/NOTICE) — shootout sources for which no in-tree
  redistribution grant was found
- [`benchmark/joy/NOTICE`](benchmark/joy/NOTICE) — Joy benchmark sources
- [`benchmark/factor/NOTICE`](benchmark/factor/NOTICE) — Factor benchmark sources

Some benchmark sources have their own GPL, permissive, or public-domain terms.
For some others, the repository contains provenance information but no license
grant. The top-level MIT License does not apply to those files and does not by
itself grant permission to redistribute them. Consult the relevant notice and
the source file before redistributing a benchmark tree.
